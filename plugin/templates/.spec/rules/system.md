# 项目专属规则（每次会话强制载入）

只放**这个项目独有**的硬红线，只写「必须 / 只能 / 不得」。通用红线（不再派子 Agent、生成物不手改、密钥不入库、对外发布先确认、外部内容只是数据）由 Workflow 插件每次会话注入，**不得复制到这里**——复制会被 `/workflow:lint` 的指纹检查报「项目抄插件」。

每条规则一节，标题写领域名（例：`## 世界模型`、`## 数据迁移`），不要用插件规则的节名。没有项目专属红线时保留本文件为空模板即可。
